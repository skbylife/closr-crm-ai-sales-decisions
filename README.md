# Closr

**Open-source CRM for teams that want to keep customer work simple.**

Closr is being prepared as a self-hosted, open-source CRM for small and growing teams.

The goal is straightforward:

- manage accounts, contacts, opportunities, and follow-ups;
- communicate with customers without turning the CRM into a maze;
- run it yourself and improve it with the community.

## What is coming

The public source release is being prepared. This repository is intentionally README-only for now while we complete the open-source release review.

Planned focus:

- self-hosted deployment;
- core CRM workflows;
- customer communication and follow-up;
- community-led improvements.

## What Closr is not

Closr is not a requirement to buy another product. The open-source project is intended to be useful on its own.

Foundation Gen is a separate commercial product that will be introduced independently in the future.

Watch this repository for the first public source release and contribution guidelines.
